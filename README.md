# Data Structures and Algorithms (DSA)

Welcome to the DSA learning repository! This repository contains implementations of various data structures, algorithms, and LeetCode problems in Java.

## 📚 Contents

### Data Structures
- **Arrays** - Basic array operations and manipulations
- **Linked Lists** - Singly and Doubly linked lists
- **Stacks** - LIFO data structure implementations
- **Queues** - FIFO data structure implementations
- **Trees** - Binary trees, BST, AVL, etc.
- **Graphs** - Graph representations and traversals

### Algorithms
- **Sorting** - Bubble, Selection, Insertion, Merge, Quick Sort, etc.
- **Searching** - Linear, Binary Search, etc.

### LeetCode Problems
- **Easy** - Beginner-friendly problems
- **Medium** - Intermediate level problems
- **Hard** - Advanced level problems

## 🚀 Getting Started

### Prerequisites
- Java JDK 8 or higher
- Basic understanding of Java programming

### Running the Code
```bash
# Compile a Java file
javac src/main/java/path/to/File.java

# Run the compiled class
java -cp src/main/java path.to.File
```

## 📖 Learning Path

1. **Start with Data Structures**
   - Understand arrays and basic operations
   - Learn about linked lists and their operations
   - Study stacks and queues
   - Move to trees and graphs

2. **Study Algorithms**
   - Begin with sorting algorithms
   - Practice searching techniques
   - Learn about recursion and dynamic programming

3. **Practice with LeetCode**
   - Start with easy problems
   - Progress to medium difficulty
   - Challenge yourself with hard problems
